# Screenshot provenance

`results/full_20261121/screenshots/final_communication_plot_capture.jpg` is the current genuine screenshot for the README. It was captured from the desktop Photos viewer while it displayed the regenerated `results/full_20261121/report_plots/exp4_communication_missed_dispatch_rate.png`. The saved capture was opened and visually checked; it shows the desktop viewer and the communication missed-dispatch plot. The source plot remains in the result directory and can be regenerated from the submitted CSVs with the documented plot command.

The former `results/full_20261121/screenshots/results_photos_view.png` was a real screenshot, but it displayed an older/different plot and therefore did not evidence the current plot linked from the README. To preserve rather than erase that audit history, its bytes were retained at `AUDIT/legacy_obsolete_screenshot.png`. It is not the submission screenshot and is not used as a current result.

No image was generated or edited to simulate experimental output. The generated overview image in the screenshots directory is a plot collage, not a desktop screenshot; it is labelled as generated in the README.
