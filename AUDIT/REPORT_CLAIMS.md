# Report claim-to-evidence map

The final manuscript is built from `report/main.tex`, generated TeX assets, and the frozen result directories. The table below identifies the source data and generating/validation path for each numerical result or evidence-bearing object. Model equations and descriptive assumptions are checked separately in `AUDIT/MATHEMATICAL_REVIEW.md` and `AUDIT/IMPLEMENTATION_REVIEW.md`.

| Report claim/object | Source of values or wording | Generation / verification |
|---|---|---|
| Objective, city, movement, call process, information boundaries, algorithms, communication, and learner | `MODEL_DESIGN.md`; `configs/default.json`; simulator and policy modules under `src/ambulance_dispatch/` | `tests/`; `AUDIT/MATHEMATICAL_REVIEW.md`; `AUDIT/IMPLEMENTATION_REVIEW.md` |
| Seven-family experiment definitions and seeds | `configs/experiment_matrix.json`; `results/full_20261121/manifest.json`; `raw_results.csv` | `python report/validate_results.py results/full_20261121` |
| Report-wide counts: 1,760 proposal episodes, 440 matched scenario groups, 20 seeds, 1,232 summary rows, 100 unilateral-deviation cases | Full-run `raw_results.csv`, `summary_metrics.csv`, deviation artifacts, manifest | Full-run validator; report macros in `report/generated/result_macros.tex` |
| Table 1: service and signed BID-to-B3 cost gap by proposal level | `results/full_20261121/summary_metrics.csv`; signed gaps cross-checked with `b3_comparisons.csv` | `report/build_report_assets.py`; full-run validator; generated `proposal_results_table.tex` |
| Table 2 and communication discussion: service, served-call response, coverage, utilization, messages, duplicate dispatch, missed dispatch; full-versus-none service difference | Full-run summaries and `derived_rates_summary.csv`; paired seed records in `b3_comparisons.csv` | Report asset builder and full-run validator; `communication_table.tex`; `AUDIT/METRIC_REVIEW.md` |
| Figure 1 and other original experiment plots | Full-run per-seed summary and comparison CSVs | `python report/plot_results.py results/full_20261121`; 15 expected plots checked by full-run validator |
| Table 3, coefficient-sensitivity figure, and sensitivity interpretation | Corrected `results/improvements_20261121/weight_sensitivity/{raw_results.csv,summary_metrics.csv,bid_gap_summary.csv}` plus `configs/weight_sensitivity.json` | `python report/plot_results.py results/improvements_20261121/weight_sensitivity`; `python tools/validate_weight_sensitivity.py results/improvements_20261121/weight_sensitivity`; generated sensitivity table and macros |
| Sensitivity counts (720 episodes, 180 level/seed groups, nine paired intervals, 20 seeds) | Corrected sensitivity raw rows, manifest, original and recovered log records | Sensitivity validator; its report records 719 original log rows plus one separately marked recovery row. The recovered log entry is not input to the metric calculations. |
| Unilateral-deviation mean, interval, and maximum | `results/full_20261121/deviations/deviation_cases.csv` and `deviation_summary.csv` | Full-run validator; macros generated by report asset builder; deviation is explicitly restricted to the tested time-only action change. |
| Table 4: member names and original assigned tasks | Original proposal PDF, preserved at `docs/reference/original-proposal.pdf` | Assignment text transcribed into `report/main.tex`; completion/authorship is explicitly labelled unverified from repository artifacts. |
| Table 5: reproduction map | Paths and verification descriptions from the submitted repository | Checked against existing source/data paths and the actual validator/report commands. |
| Abstract/introduction signed-gap and communication summary values | Generated values from full-run and sensitivity CSVs, referenced through `report/generated/result_macros.tex` | Asset generation followed by both result validators and final PDF text/render inspection. |
| Final eight-page/A4 assertion | Compiled `report/main.pdf` | Tectonic compile; `pdfinfo`; rendered page images under `report/rendered_pages/`; visual inspection; exact page count is repeated in `FINAL_AUDIT.md`. |

Generated LaTeX values are not hand-edited. The primary full-run raw episode CSV SHA-256 is checked against the pre-audit value recorded in `AUDIT/BASELINE_AUDIT.md`. The original proposal PDF SHA-256 is unchanged. See `CHANGE_IMPACT.md` for the dependency chain whenever one of these sources or outputs changed.

The proposal-results caption is generated by `write_proposal_results_table` and a regression test requires it to describe only the service and signed-gap columns actually present. This check was added after the final render audit found and corrected an obsolete response-time phrase.
